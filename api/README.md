## Конфигурация и запуск

### Создание БД
Для инициализации базы данных используйте скрипт "dbcreate".
<br>Для запуска требуется корректно настроить окружение (см. ниже)

### Пример переменных окружения
DATABASE_URL="mysql://username:password@127.0.0.1:3000/store"

### Запуск
Для запуска в режиме разработчика используйте скрипт "start:dev"
